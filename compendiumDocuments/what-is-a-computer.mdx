# What is a computer?

A <em>computer</em> is a programmable electronic device that can store, retrieve and process data.
<br />

## What are the main components of a computer?
<br />

The <em>main components</em> of a computer, which work together to process data, are the motherboard, Central Processing Unit (CPU), 
Graphics Processing Unit (GPU), Random Access Memory (RAM), and hard drive (SSD or HDD).
<br /> 

**<u>Motherboard:</u>**&nbsp;&nbsp;The motherboard is the main printed circuit board (PCB) in a computer that acts as a central hub, 
connecting all components, such as CPU, RAM, storage drives allowing them to communicate. It provides power, data pathways, and 
input/output slots for peripherals, essentially serving as the "backbone" that makes a functional system.
<br />

**<u>Central Processing Unit (CPU):</u>**&nbsp;&nbsp;A Central Processing Unit (CPU) is the primary brain of a computer, acting as the 
main processor that executes instructions, performs calculations, and manages data flow for software and hardware. CPUs have a few (4-32) 
powerful cores handling sequential processing.
<br />

**<u>Graphics Processing Unit (GPU):</u>**&nbsp;&nbsp;A Grapics Processing Unit (GPU) is a specialized electronic circuit designed to 
rapidly process data, handling thousands of small tasks simultaneously. GPUs have thousands of smaller cores built for parallel tasks. 
GPUs are mainly used for parallel processing, gaming, and artificial intelligence (AI). Modern AI models heavily rely on GPUs because 
they provide the massive parallel computing power needed to train and run complex AI models.
<br />

**<u>Random Access Memory (RAM):</u>**&nbsp;&nbsp;Random Access Memory (RAM) is a computer's short-term, high speed memory that stores 
active data for immediate access by the processor. It allows data to be read or written in any order almost instantly, acting as a 
temporary workspace that boosts performance by holding files for running applications. Crucially, RAM is volatile, meaning it clears 
its contents when the computer is turned off. RAM is used by the operating system, computer applications such as web browsers, 
integrated development environment (IDE), productivity software, etc. RAM on a computer is typically 8 GB, 16 GB, or 32 GB.
<br />

**<u>Hard Drive (SSD/HDD):</u>**&nbsp;&nbsp;A computer's hard drive is its primary non-volatile storage device used to store the operating 
system, computer applications, and user files. Non-volatile means that data is preserved even when power is removed. SSD type of drive is 
faster, quieter and more durable than HDD. SSD/HDD of a computer is typically 256 GB, 512 GB, 1 TB, or 2 TB.
