# What is Computational Complexity Theory?

<em>Computational Complexity Theory</em> is a branch of Computer Science that classifies computational problems 
according to their inherent difficulty and resource requirements.
<br />
It focuses on measuring the amount of time or space needed to solve a specific problem.
<br />
**<u>Turing Machine:</u>**&nbsp;&nbsp;A Turing Machine is an abstract model of computation that reads and writes symbols on an infinite tape.

**<u>Deterministic Turing Machine:</u>**&nbsp;&nbsp;A Turing Machine that can only follow one path of execution. At any given step, the machine’s current state and symbol under the tape head uniquely define exactly what the next step will be. There is only one possible sequence of events for any given input.

**<u>Nondeterministic Turing Machine:</u>**&nbsp;&nbsp;A Turing Machine that can branch into multiple paths of execution simultaneously. It will have successfully solved a problem if any branch of execution provides a correct result.
<br />
**Big $\boldsymbol{O}$ notation**&nbsp;&nbsp;is a mathematical tool used in computer science to describe the asymptotic upper bound of a solution's performance.

**Big $\boldsymbol{\Theta}$ notation**&nbsp;&nbsp;is a mathematical tool used in computer science to describe the exact asymptotic behavior or "tight bound" of a solutions's performance.

**Big $\boldsymbol{\Omega}$ notation**&nbsp;&nbsp;is a mathematical tool used in computer science to describe the asymptotic lower bound of a solution's performance. 
<br />

**<u>Time Complexity</u>**&nbsp;&nbsp;measures how the execution time, measured in number of operations, of a solution grows relative to the size of the input.

**<u>Space Complexity</u>**&nbsp;&nbsp;measures the total amount of memory or storage a solution requires based on the input size.

| Notation | Name | Growth Rate Description |
| :--- | :--- | :--- |
| $O(1)$ | Constant | Resources needed remains the same regardless of input size |
| $O(log\;n)$ | Logarithmic | Resources needed grows with respect to logarithm of input size |
| $O(n)$ | Linear | Resources needed grows in direct proportion to input size |
| $O(nlog\;n)$ | Linearithmic | Resources needed grows with respect to the input size multiplied to the logarithm of the input size |
| $O(n²)$ | Quadratic | Resources needed grows with respect to the input size squared |
| $O(2ⁿ)$ | Exponential | Resources needed doubles every time input size increases by 1 |
| $O(n!)$ | Factorial | Resources needed multiplies by the input size every time input size increases by 1 |

## Complexity Classes 
<br />
**<u>Complexity Classes</u>**&nbsp;&nbsp;are groupings of computational problems by the time or space resources required to solve them.
<br />
### Time Complexity Classes:
<br />
**<u>P (Polynomial):</u>**&nbsp;&nbsp;Problems that can be solved within a polynomial amount of time.

**<u>NP (Nondeterministic Polynomial):</u>**&nbsp;&nbsp;Problems where a candidate solution can be verified in a polynomial amount of time, even if finding the solution takes much longer.

**<u>NP-Hard:</u>**&nbsp;&nbsp;Problems that are at least as hard as the problems in NP, but they are not necessarily in NP. A problem is considered NP-Hard if any problem in NP can be reduced to it in polynomial time. 

**<u>NP-Complete:</u>**&nbsp;&nbsp;The hardest problems within NP. Any problem in NP can be reduced to any NP-Complete problem in polynomial time. Therefore, any solution to an NP-Complete problem can be used to solve any problem in NP. 
<br />
### Space Complexity Classes:
<br />
**<u>L (Logarithmic Space):</u>**&nbsp;&nbsp;Problems that can be solved on a Determistic Turing Machine using space bounded by the logarithm of the input size.

**<u>NL (Nondeterministic Logarithmic Space):</u>**&nbsp;&nbsp;Problems that can be solved on a Nondeterministic Turing Machine using space bounded by the logarithm of the input size.

**<u>PSPACE (Polynomial Space):</u>**&nbsp;&nbsp;Problems that can be solved on a Deterministic Turing Machine using space bounded by a polynomial function of the input size.

**<u>NPSPACE (Nondeterministic Polynomial Space):</u>**&nbsp;&nbsp;Problems that can be solved on a Nondeterministic Turing Machine using space bounded by a polynomial function of the input size.
